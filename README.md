# 🏏 Cricbuzz LiveStats: Real-Time Cricket Insights & SQL-Based Analytics

A multi-page Streamlit dashboard that combines live data from the Cricbuzz API
with a PostgreSQL database for SQL analytics (25 queries) and CRUD operations.

> **Status:** under construction. Full documentation is written in Phase 17.

## Quick start (will be finalised later)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate     macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then fill in your keys
streamlit run app.py
```
